# My Homepage

A responsive personal homepage built with React + Vite.

**Live site:** https://lab12-web-one.vercel.app <!-- replace with your real URL -->

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Tech
React, Vite, semantic HTML, responsive CSS. Deployed from GitHub with automatic redeploys on every push to `main`.
